# PLK Monitor — instalator

Wersja: **1.0.2** · Windows 10/11 (64-bit) · instalacja bez uprawnień administratora.

SHA-256: `a64de9cf36825309e257f7348dfc861a72abb98729ef11360fc7ed5c42d64fdd`

## Instalacja (2 minuty)

1. Pobierz i uruchom `PLK-Monitor-Setup.exe`.
2. Jeśli Windows pokaże „System Windows ochronił ten komputer” → **Więcej informacji** → **Uruchom mimo to**
   (instalator nie ma płatnego certyfikatu).
3. **Dalej → Zainstaluj → Zakończ**.
4. W okienku PLK Monitor kliknij **„Połącz z dashboardem”**, w przeglądarce **„Połącz urządzenie”**.
5. Kliknij **„Włącz monitoring”**. Gotowe.

Dashboard: https://plk-ai-dashboard.vercel.app

To repozytorium zawiera wyłącznie instalator — bez kodu, haseł ani kluczy.
